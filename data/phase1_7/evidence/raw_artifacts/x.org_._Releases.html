Current release

X.Org no longer produces unified releases of the entire X Window System, but instead releases individual X.Org modules as needed - see the xorg-announce archives for details of those releases.

  • Download: mirrors, master site, gitlab repos.

Old releases

  • X11R7.7 (Released: 2012-06-06). Release Notes. Of note, this release added multitouch input support, Fence synchronization primitives, and pointer barriers.
    • Download: mirrors, master site.
  • X11R7.6 (Released: 2010-12-20) Release Notes. Of note, this release added xorg.conf.d directories, InputClass configuration sections, udev support on Linux, improved documentation, and integrated xcb.
    • Download: mirrors, master site.
  • X11R7.5 (Released: 2009-10-26) Release Notes. Of note, this release added Multi-Pointer X (MPX), RandR 1.3, E-EDID support and DRI2.
    • Download: mirrors, master site.
  • X11R7.4 (Released: 2008-09-23) Release Notes
    • Download: mirrors, master site.
  • X11R7.3 (Released: 2007-09-06) Release Notes Of note, this release added RandR 1.2 and input hotplug support.
    • Download: mirrors, master site.
  • X11R7.2 (Released: 2007-02-15) Of note, this release added autoconfiguration support, and enhanced support for GL-based compositing managers, such as Compiz and Beryl.
    • Download: mirrors, master site.
  • X11R7.1 (Released: 2006-05-22) Release Notes
    • Download: mirrors, master site.
  • X11R7.0 (Released: 2005-12-21)
    • Download: mirrors, master site.

For more complete information, including a release history, please see the historical releases page.
