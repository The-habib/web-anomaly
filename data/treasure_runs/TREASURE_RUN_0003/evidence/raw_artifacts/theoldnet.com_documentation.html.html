Changelog Ordered by Newest to Oldest Features (roughly)

- Homepage Auto Indexer -- In an effort to log and display all of the hidden gems on Geocities, AOL members pages, etc, the site checks all site requests that users makes and if they match a series of regular expressions the site is tagged and saved. The saved homepages are presented to users on the main site for ease of discovery.

- Guest book -- A working guestbook, sign it!

- Bot deflection -- Put in a handful of measures to keep bots from causing unnecessary load to proxy and cache. And to prevent skewing data.

- Debugging Endpoint - Use /raw?url="" instead of /get?url="" when needing to see if failed site content is due to a but in theoldnet.com or with the source snapshot

- Detecing browser User Agents and showing a stats table of the most popular browsers used.

- HTML 1.0 support - Tested with Netscape 0.93 and Mosaic 2.5.

- Search Engine - Able to search for sites by query instead of explicit domain name

- Ability to see all sites that have been discovered through TheOldNet

- Count - Showing total pages parsed and served, and total number of users

- Ability for user to enable/disable javascript and enable/disable encoding

- Much better link and image rebuilding

- Discovery of site by listing Recently viewed sites and Most visited sites

- Searching by Year

- Ability to search "the old net", via Archive.org API on old browsers because all modern, incompatible content is removed by theoldnet's parser/proxy ( the entire purpose of the site )


Legal


OK let's get the legal stuff out of the way. If you use this site, to find old internet content, the site is aware of what you were looking for. This should be painfully obvious. There is absolutely no way this product could do what it does, without knowing what you're trying to do with it.
Now because the site has this awareness, we can now do cool things with that data. Such as provide these lost sites and homepages to other users, because you've already done the hard work of trying to find them.
Nothing about you, personally is identifiable. With the exception of the handle that you supply when you choose to sign the guestbook
If you don't want this site to have knowledge of what you are looking for then you should not use the site. You could use archive.org directly.

Legal Liability: TheOldNet.com is incapable of being responsible for the queries requested by end-users or the content served up as a result by the Internet Archive. It is a dumb, pass-through proxy. If the content exists in the Internet Archive, and the content is requested by the end user, theoldnet will blindly pass the rearch result from the Internet Archive to the end user. If this content, provided by the Internet Archive is illegal, there is absolutely no way for TheOldNet to make that determination. If the content is illegal and should be removed from the Internet, that must happen at the source of the content, which is the Internet Archive. A request to take down the content should be made with them directly here. TheOldNet has no capability of removing this content from the internet.
