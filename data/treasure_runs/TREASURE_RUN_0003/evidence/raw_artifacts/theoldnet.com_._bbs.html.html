That's right, The Old Net is now The Old BBS!

By using a Commodore 64 equipped with a WIFI modem, or by using a program called syncTerm, you can browse theoldnet.com via a BBS/telnet connection.

If you have a C64 but dont have a WIFI modem I seriously recommend it. Lots of fun to be had on dozens of BBSes that are still maintained.

If you don't have a C64 or just want to use a modern computer you can get syncTERM HERE
syncTERM works on Windows, Mac and Linux. All you have to do when setting up the connection is make sure Screen Mode is set to C64.
