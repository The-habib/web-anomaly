What is Building X?

Building X is a platform that runs the applications that help you manage building operations. It provides a central foundation of secure, real-time data that supports a wide range of use cases.

The applications offered for the Building X platform cover all industries and core building use case categories:

  • Energy and sustainability
  • Safety and security

Frequently asked questions

Connectivity: Building X is an open platform that is vendor agnostic. To get your data into the platform, we offer holistic software and hardware connectivity solutions, from native cloud-connected Siemens hardware and software building management systems, to hardware and software gateways.

You do not need to have Siemens devices installed and collecting your building data. We support several standard protocols so our gateways and building management systems will work with your current installations. Learn more about connectivity.

Deployment: Building X is based on AWS. We provide Building X with a hosting service included, so you can get value without any effort or maintenance. Deployment is done by Siemens.

Building X is a digital building platform. To get started, you buy a subscription to Building X applications or APIs aligned to your target use cases.

You do not need to buy all Building X applications. You can start small with a single app and scale as needed. When an app is subscribed to, you gain access to a central launch pad where all can be viewed.

Before getting started with these apps, you need to get data flowing from your buildings to the Building X platform. To learn about connectivity options and available device mapping and implementation assistance, visit the buyer's guide.
