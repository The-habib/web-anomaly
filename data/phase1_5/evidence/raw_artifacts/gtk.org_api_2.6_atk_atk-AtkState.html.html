Welcome to GNOME GitLab

gitlab.gnome.org is a GitLab instance dedicated to development of the GNOME project and its ecosystem.

If you would like to contribute, you can create a new account here.

Contributors associated with the GNOME Foundation should use their GNOME account to sign in by using the "GNOME Keycloak" login option.
