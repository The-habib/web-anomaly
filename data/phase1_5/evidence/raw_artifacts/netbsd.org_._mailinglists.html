NetBSD mailing lists

Introduction

The NetBSD Project provides a variety of public mailing lists to facilitate communication between the users and developers of NetBSD. All of the mailing lists are served by the Majordomo mailing list management package, and you can find out more about how to use the NetBSD Project's Majordomo by mailing <majordomo@NetBSD.org> with an empty message body.

Please note that to reduce spam and improve accessibility, NetBSD mailing lists only accept plain text email, which many email clients don't send by default. The Use Plaintext Email website has advice on configuring various email clients to use plain text.

We ask that you avoid posting LLM/AI-generated material to the mailing lists. If you use LLMs or generative AI to help with translating from your native language, that's fine; just make sure to note that you did this in your message, to help provide context if there's misunderstanding. But please don't, for example, answer someone's questions by forwarding them to an AI and then copying and pasting the AI's answer—if someone wanted an answer from an AI instead of the human NetBSD community, they wouldn't have gone to the mailing list. If you're posting to our lists, what you're saying should come from you, not from a machine.

To unsubscribe from a mailing list send an email message to <majordomo@NetBSD.org> containing only the message unsubscribe listname.

Note

Any and all posts to our mailing lists are archived across the internet virtually forever and are impossible for us to remove. Please consider any content, including the email address used to post to the list, as public information. You may also wish to consider this when engaging in personal conversations with other members on the public mailing lists.

current-users:
This is a forum for all people using an up-to-date version of the NetBSD-current source tree. It is a good forum for talking about `gotchas' in the tree. Since the NetBSD-current tree is a quickly moving target, please confirm any problems with the latest tree before posting. 		Subscribe Browse NNTP

This mailing list is for announcements about NetBSD. 		Subscribe Browse NNTP

This mailing list is where you can discuss bugs in NetBSD. All NetBSD bug reports sent with send-pr(1) appear here. 		Subscribe Browse NNTP

This mailing list is receives reports from the NetBSD Continuous Integration (CI) infrastructure and discussion about it. 		Subscribe Browse

netbsd-ports:
This list is for people working on or generally interested in ports of NetBSD to various types of computers. 		Subscribe Browse NNTP
netbsd-syzbot:
This mailing list receives bug reports and status updates for bugs found in the NetBSD kernel by Google's syzkaller / syzbot kernel fuzzing tool. This list is a local copy of mail sent to the <syzkaller-netbsd-bugs@googlegroups.com> Google Group. Please do not send mail directly to this NetBSD.org list, because anyone subscribed directly to the Google Group will not receive it. See the syzkaller documentation and the syzbot documentation for more information about this tool and service. 		Subscribe Browse
netbsd-users:
This list provides a general help forum where users can discuss using NetBSD, regardless of platform. As a large number of subscribers receive this list, please use your good judgement when posting. Technical discussion related to the development and design of NetBSD itself aren't appropriate on this list and are better voiced in a more narrowly-focused technical list. 		Subscribe Browse NNTP
pkgsrc-bugs:
All bug reports in category “pkg” sent with send-pr(1) appear here. Please do not report your bugs here. 		Subscribe Browse NNTP
pkgsrc-bulk:

pkgsrc-changes:
This list is for those who are interested in getting a commit message with the diff of the change attached for every change committed to the NetBSD Packages Collection (pkgsrc). It is also available in digest form, meaning one daily message containing all commit messages for changes to the package source tree in that 24 hour period. 		Subscribe Browse NNTP
pkgsrc-users:
This is a general-purpose list for most issues regarding the NetBSD Packages Collection (pkgsrc), regardless of platform, e.g. soliciting user help for pkgsrc configuration, unexpected build failures, using particular packages, upgrading pkgsrc installations, questions regarding the pkgsrc release branches, etc. General announcements or proposals for changes that impact the pkgsrc user community, e.g. major infrastructure changes, new features, package removals, etc., may also be posted. 		Subscribe Browse NNTP
