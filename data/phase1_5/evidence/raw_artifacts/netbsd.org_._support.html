NetBSD support

The most important source of support is the NetBSD community itself. The community section lists various resources on where to get help in case you encounter any problems.

There are also a number of consultants for hire in case you need commercial support.

Supported Hardware

In case you need to know if a certain piece of hardware is supported by NetBSD, check the list of supported hardware devices.

Problem Reports

Found a bug? Please let us know.

Before submitting a report, please search the PR database to check if a report already exists for the issue.

  • Query the PR database
