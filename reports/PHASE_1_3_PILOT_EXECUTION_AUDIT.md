## 2. Evidence Findings

1. **No External Network Activity**: The execution of `atlas pilot run` in Phase 1.2 completed in less than 2 seconds for 200 domains. A true live network scan of 200 domains with Wayback and Common Crawl queries requires at least 60–120 seconds even with concurrency.
2. **Hardcoded Domain Branching**: Specific domains (`spacejam.com`, `stallman.org`, `toastytech.com`) were assigned custom attributes (e.g. `has_frameset = True`, `sim_score = 0.94`) via in-memory python code rather than live HTML parsers.
3. **Absence of Raw WARC / HTML Payloads**: `data/phase1_2_pilot/evidence/` contained JSONL metadata records generated by code, not raw HTTP response bodies.
