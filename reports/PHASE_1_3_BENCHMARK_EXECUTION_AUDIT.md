## 2. Evidence Findings

1. **Domain Names Were Real**: The 30 reference domains in `data/benchmark_v1/benchmark_domains.csv` represent genuine, verified public entities (e.g. `google.com`, `apple.com`, `spacejam.com`, `stallman.org`, `ietf.org`).
2. **Evaluated Evidence Was Synthetic**: The input features fed into `score_single_evidence()` were generated by the simulation function `_generate_realistic_domain_evidence()` rather than extracted from live HTTP/Wayback artifacts.
3. **Report Misclassification**: The output report `BENCHMARK_RESULTS.md` presented the resulting 90.0% accuracy and 100.0% precision as if they were derived from live web observations.

## 3. Final Audit Classification

$$\mathbf{STATUS: \text{ BENCHMARK\_FIXTURE (SIMULATED)}}$$

### Remediation Actions:
1. Re-label Benchmark v1 as a **synthetic unit regression benchmark** in project documentation.
2. Build **Benchmark v2** in `data/benchmark_v2/` which collects genuine live HTTP responses and Wayback CDX queries before scoring and blinded label evaluation.
